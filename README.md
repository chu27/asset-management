# 资产管理

**当前版本：1.0**  
**版本日期：2026-08-16**

一款在本机运行的个人股票与多币种资产管理网页应用，用于记录买卖、查看持仓、统计现金、定存和基金、分析股票结构并管理投资通知。

数据默认保存在本机 SQLite 数据库中，不需要连接证券账户，也不会自动上传个人资产数据。

## 主要功能

### 资产总览

- 统一统计股票、现金、定存和基金。
- 支持日元、美元和人民币资产。
- 显示全部资产折合日元和折合人民币总额。
- 四张饼图展示各币种资产构成和货币占比。
- 饼图外侧及图例显示金额和百分比。
- 点击日元、美元或人民币资产构成卡片，可跳转到对应资产明细；点击明细标题可返回对应图表。
- 使用 Frankfurter API 更新汇率；失败时保留最后一次成功数据。

### 持仓与交易

- 按日股、美股和科创分别显示持仓。
- 股票代码必填，股票名称选填。
- 记录买入、卖出、手续费、税费和交易原因。
- 自动使用移动平均成本法计算持仓成本和盈亏。
- 盈亏金额和百分比同步显示，百分比保留两位小数。
- 支持按日期和市场筛选交易记录。
- 支持修改或删除交易记录，并重新计算持仓和关联现金余额。
- 支持点击股票代码手动修改当前价格。
- 支持通过 yfinance 批量查询行情；查询后先预览、允许修改，确认后才保存。未取得行情时保留原价格。

### 分析

- 自动同步当前持仓股票。
- 设置自定义 Tag、止损点、止盈点和仓位上限。
- 输入止损点或止盈点时立即计算相对持仓成本的百分比。
- 按板块显示 Tag 对应的股票资产占比。
- 以每周为单位显示股票资产历史变化折线图。
- 支持月度和年度投资复盘。

### 通知中心

- 显示止损、止盈、仓位和亏损幅度通知。
- 管理财报、分红除权、期权日和自定义事件。
- 支持统一风险规则和单只股票规则。
- 所有通知仅用于提示，不会自动买卖股票。

## 技术栈

- 后端：Python、FastAPI、SQLAlchemy、SQLite。
- 前端：React、TypeScript、Vite、Recharts。
- 股票行情：yfinance。
- 汇率：Frankfurter API。

## macOS 一键启动

运行前需要安装：

- Python 3。
- Node.js 和 npm。

下载项目后，双击：

`启动SBI.command`

启动文件会自动：

1. 创建 Python 虚拟环境。
2. 安装后端依赖。
3. 安装前端依赖。
4. 启动前后端服务。
5. 打开 `http://127.0.0.1:3002/`。

关闭启动文件打开的终端窗口后，本地服务会停止。

如果 macOS 阻止首次运行，可以在终端进入项目目录后执行：

```bash
chmod +x 启动SBI.command
```

然后再次双击启动文件。

## 手动启动

后端：

```bash
cd backend
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
PYTHONPATH=. .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8010
```

另开一个终端启动前端：

```bash
cd frontend
npm install
npm run dev
```

然后打开 `http://127.0.0.1:3002/`。

## 数据与隐私

本机数据文件位于：

`backend/sbi.db`

该文件已加入 `.gitignore`，不会提交到 GitHub。建议定期单独备份。删除数据库后，软件会在下次启动时重新创建数据库并加入初始示例数据。

浏览器中自行编辑的软件名称、图标文字和标语保存在浏览器本地存储中，不写入数据库。
